Cloud File Security & Storage System

Secure file storage using 1 MB block segmentation, AES-256-GCM encryption, AWS S3, and SHA-256 integrity verification.

Test the Application

Notice: The file processing backend must be run locally to test file segmentation, AES-256-GCM encryption, AWS S3 upload, and SHA-256 reconstruction. Start the Flask server with python app.py and open http://127.0.0.1:5000.

How It Works

  1. Select a file.
  2. Split the file into 1 MB blocks.
  3. Encrypt each block using AES-256-GCM.
  4. Upload encrypted blocks to a private AWS S3 bucket.
  5. Download the encrypted blocks.
  6. Decrypt and reconstruct the original file.
  7. Verify file integrity using SHA-256.

Technologies Used

  • Python
  • Flask
  • AES-256-GCM
  • SHA-256
  • AWS S3
  • Cloudflare Pages (portfolio hosting)
